Para clonar este repositorio, deberás de crear una carpeta nueva con el nombre que desees que tenga. Y desde la terminal de visual estudio, 
podrás clonar el proyecto.
--IMPORTANTE--
Antes de clonar el repositorio, desde la terminal de VS code. Asegurate que la ubicación de directorio sea en la carpeta que creaste especialmente 
para el proyecto, en dado caso de equivocarte tendras que borrar y empezar de cero.
